# 深度学习课程

## 线性回归

线性回归使用输入特征的加权和预测连续值。训练时通常最小化均方误差，梯度下降负责更新权重和偏置。

## 逻辑回归

逻辑回归通过 Sigmoid 函数把线性输出映射为概率，常用于二分类。其损失函数通常是二元交叉熵。

## 反向传播

反向传播依据链式法则，从输出层向输入层逐层计算损失函数对参数的梯度，并将梯度交给优化器更新参数。

## 激活函数

ReLU 在输入大于零时输出输入，否则输出零。Sigmoid 容易在饱和区产生梯度消失，ReLU 能缓解深层网络的这一问题。

## 卷积神经网络

卷积核通过局部连接和参数共享提取空间特征。池化层可降低空间分辨率，并增强一定的平移不变性。

## 循环神经网络

循环神经网络使用隐藏状态处理序列。长序列训练可能发生梯度消失或爆炸，LSTM 通过门控机制改善长期依赖建模。

## 注意力机制

注意力使用 Query 与 Key 的相似度计算权重，再对 Value 加权求和。缩放点积注意力会除以键向量维度平方根。

## Transformer

Transformer 依赖多头自注意力和位置编码并行建模序列，不使用循环结构。编码器还包含前馈网络、残差连接和层归一化。

## 正则化

L2 正则化惩罚过大的权重；Dropout 在训练时随机屏蔽部分神经元。早停法根据验证集表现终止训练，以缓解过拟合。

## 模型评估

分类任务可使用准确率、精确率、召回率和 F1。类别不平衡时不能只看准确率，混淆矩阵和 PR 曲线通常更有解释力。
